## 第一轮：16 条（7 必修 / 7 应改 / 2 建议）

全部属实。处置：claims.md 与 metrics.md 重写为 v2，新增 ADR 0012。要点：

| 条 | 处置 |
|---|---|
| 必修 1 两臂表达力不对等 | 表达力对齐三清单（任务 ID / 指令面 / 支持集）预注册；支持集外任务不计入 C1；无限制 C API 臂单独报告；W2 在 Cube 落地前标「未测」 |
| 必修 2 判词不是一个函数 | v2 引入判词表（v2.1 再修订为唯一版本） |
| 必修 3 M0 比值方向 | 公式写死 `tax = T_generated / T_handwritten − 1`，正值为更慢；中位语义与配对集写明 |
| 必修 4 M3 矛盾 + plateau 偷渡基线 | 删「或与 M1 之二成立」；plateau 独立成条款；100% 检查点不构成 plateau；3% 改相对值；eligible 定义 |
| 必修 5 token/B/成功/逃逸无操作定义 | token 计全部（v2.1 修订为任务书等额不占 B）；B = 试点首次正确 token 最大值 × 3；上板 ≤ 20 固定；逃逸只扫 IR 臂源码、候选不计入任何指标、全逃逸记失败 |
| 必修 6 计时口径与离线防污染 | 测量清单逐项冻结；基线须同设备同流程重测；源码/包/csv 哈希归档；判分只读 csv；M0 钉 950；HAP 公式写入 |
| 必修 7 注入集撑不起门禁 | 通过线唯一化并含干净率；分母预注册；V008 标未测；金标双人冻结；另设非反写故障集；合法样本含边界例 |
| 应改 8 R=5 单次翻转 | 成功数 < 3 判不确定；M2 差 1 次不直接否决（v2.1 并入判词表前置检查） |
| 应改 9 阈值无依据 | 全部标注提案值，冻结须写明来源；守卫开销配对列入 M0 必测 |
| 应改 10 M9 跑不起来 | 改三档（v2.1 再修订为全不上板） |
| 应改 11 M0 孪生对照 | 配对集扩为四类；孪生税单独报告不进通过线 |
| 应改 12 表达力自选分母 | 分母 = 完整种子清单含 gap；回测只用未看过内核；准入 k=2；未核对族不计入分子；重算前标「未达冻结线」 |
| 应改 13 Gspan 无分母 | 分母同 M1 基线；失败 shape 记 0 使 Gspan 为 0；shape 集带哈希/日期/托管位置提前入仓 |
| 应改 14 合法但慢无指标 | 无效候选占比随 C1 采集，触发 ADR 0005 回摆（v2.1 修订定义） |
| 建议 15 工具链 vs 表示 | C1 主张改名「工具链」；表示层需「同一 IR 关诊断」臂 |
| 建议 16 上手成本/演化 | C1 不构成学习曲线证据；examples/ 对两臂不可见并记录检索日志 |

## 第二轮：12 条（4 必修 / 7 应改 / 1 建议）

全部属实。处置：claims.md 与 metrics.md 修订为 v2.1。

| 条 | 处置 |
|---|---|
| 必修 1 成立式仍含 plateau | 判赢式删掉「或 plateau 更多」；plateau 只作独立报告；离线闭环须在 20/40/60/80% 处归档当时最佳，禁止回填 |
| 必修 2 两份文件两个判词 | rel 公式唯一（`median(A_IR)/median(A_control) − 1`）；判词只在 claims.md；metrics 删除局部说法改为指向 |
| 必修 3 负载级可二选一 + 空集 | 任务级改三档；负载级无「或」按序匹配表；空集记未测；任务清单 = 支持集 ∩ level1 全部，禁止再删 |
| 必修 4 对照臂越面无作废 | 对照臂面扫描与 M7 同级；越面候选不进 M1/M2/M3；无合规正确内核记失败；扫描脚本随协议冻结 |
| 应改 5 成功数 <3 仍可否决 | 前置检查先于判词公式；不成立改合取结构（M2 少 ≥ 2，或两侧 ≥ 3 且 rel ≤ −5%） |
| 应改 6 B 与上板可改写 | B = 两次试点最大值 × 3；试点失败追加并归档不得挑选；上板 20 固定；任务书等额不占 B |
| 应改 7 M0 中位被孪生冲掉 | 通过线分母只含去守卫对照与每 op 短 tile 配对；孪生税单独报告；M0b 与 C1 同容差，逐位率只报告 |
| 应改 8 C3 纪律没进注入集 | 脚本在新纪律落地前只打印「旧集回归通过，C3 未测」；verifier-rules.md 通过线对齐 |
| 应改 9 M9 第三档无日志 | 三档全不上板：完整诊断 / 仅 message / 仅规则 ID；K=5 写回；最小差值预注册（修复率 +0.2、每档 ≥ 20 故障）；未达标 C3 改称「检查器拦截」 |
| 应改 10 无效候选触发线是空的 | 只保留「慢于已重测基线 4 倍」；触发值 0.5 提案；基线未重测记未测；写回 ADR 0005 |
| 应改 11 HAP 可负 | T_HW 写明时延下界；仅 T_cand、T_baseline 都大于 T_HW 时计算，否则未测；C4 以中位 speedup 为主，HAP 作附注 |
| 建议 12 处置记录指向错误 | 即本文；claims.md 与 ADR 0012 的链接已修正 |
