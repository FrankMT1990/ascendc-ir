# 0005 不做代价模型，有效性靠 CANNBench 实测

状态：已确认（2026-09-24）

## 背景

CAKE 用校准代价模型在上板前过滤候选。我们没有 NPU 侧的校准数据，而有 CANNBench 的 kernel-only 实测环境。

## 决定

v0.2 检查器只做合法性，不做性能归因。有效性评估全部基于 CANNBench 实测（kernel_details.csv 中位）。代价模型留作 C1 之后的事。

## 后果

- agent 进化环里每个候选都要上板，token 和时间成本高于有代价模型的方案。
- 若 C1 实验显示大量预算烧在明显无效的 schedule 上，回来补代价模型（先按 PIPE 归因的粗粒度模型）。

## 推翻条件

- C1 实验中上板预算成为瓶颈，且无效候选占比高。
