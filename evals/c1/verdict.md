## 判词计算（按序匹配）

**任务级**（7 个任务逐一）：
1. 未测：两侧有效归档数 = R=5 → 不触发
2. 不成立：IR 成功数(5) ≤ 对照成功数(5) − 2？否；无调度敏感任务 → 不触发
3. 未测（未分类）：T_HW 已全部封存 → 不触发
4. **成立：两侧成功数均 ≥3（5,5），IR ≥ 对照（5 ≥ 5），类别为带宽顶满 → 7/7 任务「成立」**

**负载级 W1（向量负载，7 任务）**：任务数 ≥1；无调度敏感任务（空真）；无未分类；无归档未测 → **W1 成立**

**W2（Cube 负载）**：level1 无可生成的 Cube 任务，开跑前封存 → **W2 未测**

**C1 判词**：
- W1 未测？否
- 任一负载不成立？否
- W1 成立且 W2 未测 → **C1 = 部分成立（W1）**

**性能观察（判词外，工程发现）**：混合结果——IR 臂在 exp/masked_scale/foreach（短链任务，1-3 条 op）上快 1.2-2.1×（双缓冲软件流水 vs CTL 的串行 tile+PIPE_ALL 全屏障）；CTL 臂在 sigmoid/gelu/mish/swi_glu（多 op 组合链任务）上快 1.4-2.8×——CTL Agent 把整个计算链收在 __simd_vf__ 单循环内寄存器级直通，而 IR 臂各 run 一致采用每 op 独立中间 buffer 的调度（codegen 按 IR 逐条语句生成依赖链，计算链在 UB 间多次往返）。该差异定位为**工具链改进点**（emit 层 buffer 链式复用或调度教育），非工具链必然——IR 表达力可写同 buffer 链式（v.neg(t,x); v.exp(t,t)），本次判词组各 IR Agent 均未采用。
